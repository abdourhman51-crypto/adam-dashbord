# مركز قيادة آدم — Adam Mission Control

لوحة تحليلات عربية (RTL) لمنصة **آدم** للمرافقة التربوية، مبنية على البيانات الحية من Supabase.

## التشغيل

```bash
npm install
npm run dev
# ثم افتح http://localhost:3000
```

المتغيرات في `.env.local` مضبوطة مسبقاً (رابط المشروع + مفتاح anon).
لفتح الجداول المحمية بـ RLS (مثل `follower_insights`)، أضف مفتاح `SUPABASE_SERVICE_ROLE_KEY`
من إعدادات Supabase → API. يُستخدم على الخادم فقط ولا يصل إلى المتصفح.

## الصفحات

| المسار | الغرض |
|---|---|
| `/` | نظرة عامة: مؤشرات رئيسية، نمو المتابعين، القمع، رؤى ذكية |
| `/funnel` | قمع التحويل، حالات العروض، عروض تحتاج متابعة، ملخص التجديدات |
| `/followers` | سجل المتابعين: بحث/تصفية/ترتيب/تصدير CSV + ملف تفصيلي لكل متابع |
| `/conversations` | إحصاءات المحادثات، أعمق الجلسات، الجلسات الحية |
| `/program` | البرنامج التربوي: الخطط، الاختراقات، التحديات الحقيقية، الأحداث |
| `/revenue` | الاشتراكات، التسعير حسب الدولة، سجل المدفوعات |
| `/system` | صحة النظام: قضايا الأمان وجودة البيانات مع توصيات الإصلاح |

## البنية

- **Next.js 15 (App Router) + TypeScript** — صفحات Server Components تجلب البيانات على الخادم مع `revalidate: 60` (تخزين مؤقت ذكي).
- **Tailwind CSS 4** — نظام ألوان آدم (أخضر الغابة `#1F4D2E` + ذهبي `#D4A017`) عبر CSS variables مع وضع فاتح/داكن كامل.
- **Recharts** — الرسوم البيانية؛ **lucide-react** — الأيقونات.
- `lib/queries.ts` — طبقة الوصول للبيانات (كل استعلامات Supabase).
- `lib/insights.ts` — محرك الرؤى: قواعد صريحة تستنتج فرصاً ومخاطر من البيانات.
- `lib/format.ts` — تنسيق عربي (أرقام، تواريخ، نسب) وترجمات حالات النظام.

## قرارات مبنية على الواقع

- **لا بيانات مُختلقة**: كل رقم يأتي من الجداول الفعلية. حيثما تنقص البيانات
  (payments فارغ، بلا عمود زمني للمحادثات، الدولة غير مسجَّلة) تعرض اللوحة
  الملاحظة بشفافية مع التوصية المعمارية في صفحة «صحة النظام».
- **الإيراد تقديري** حتى يبدأ تسجيل المدفوعات في جدول `payments`.
